核心建模原则对照

✅能力驱动而非型号驱动 —— 分配器读 BMS 可用功率，不认厂商
✅点位统一抽象为 Point —— 完整
⚠️设备异构通过 Adapter 屏蔽 —— 用 Profile 替代（更轻，但无独立 Adapter 层）
❌层级拓扑建模（Site→Plant→EnergyUnit）—— 实际是「通道→站号→点位」扁平模型
❌调度对象是 EnergyUnit 而非设备型号 —— 调度对象仍是「通道站号/设备」
❌支持单场站扩展到多场站 —— 单机，无多场站

结论：easyems 的领域模型是「Modbus 通道导向」（通道→站号→点位），图的领域模型是「能力/业务导向」（Site→Plant→EnergyUnit→Device→Point）。底层 Point/Device/AlarmEvent 覆盖完整，中间缺的 EnergyUnit 抽象是根子——补上它（及其上的 Site/Plant 层级），分配器、聚合、调度才有正确挂载点，多柜/多站才顺理成章。
