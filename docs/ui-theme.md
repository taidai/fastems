主题源文件：`docs/assets/glass-theme.css`（来自 `zizu_v3/docs/design/glass-theme.css`）

## 1. 气质

背景照片保持清晰，玻璃只在卡片内部发生。页面是明亮的，文字使用深蓝墨色，卡片是 125° 的双层蓝白渐变并带 24px 背景模糊。绿色表示光伏/充电，蓝色表示直流母线，红色表示告警；不使用大面积橙色主按钮。

## 2. 令牌

| 角色 | 值 | 用法 |
| --- | --- | --- |
| 主文字 | `#1f3550` | 标题、数值 |
| 次文字 | `#5b7590` | 标签、单位、说明 |
| 弱文字 | `#647b91` | 脚注、时间 |
| 光伏/充电绿 | `#2B8A57` | 光伏、充电、正常、主按钮 |
| 直流蓝 | `#2f6f9f` | 储能、直流母线、链接与焦点 |
| 告警红 | `#b23a32` | 严重告警 |
| 警告琥珀 | `#9a6a1f` | 仅警告文字与边框；不用于主按钮 |
| 卡片下缘透明度 | `0.62` | `--glass-opacity`，显示设置中的“玻璃透明度”默认值 |
| 卡片上缘透明度 | `0.86` | `--panel-opacity`，由透明度 +0.24 得到 |
| 玻璃模糊 | `blur(24px) saturate(140%)` | 卡片、顶栏、底栏本身 |
| 圆角 | `10px` | 卡片统一圆角 |
| 卡片间距 | `14px` | KPI 与主要卡片 |

卡片渐变：

```css
linear-gradient(125deg, rgba(246,251,255,.86), rgba(225,237,250,.62))
```

描边与内高光：

```css
border: 1px solid rgba(255,255,255,.34);
box-shadow: inset 0 1px 0 rgba(255,255,255,.32);
```

重点卡片（KPI、能流、顶栏、底栏）叠加 `.zz-panel--hero` 的内外高光与 1px 蓝灰环。

背景：

- 照片不做整体模糊，只做亮度调节（默认 78%）；
- 顶部叠一层 `rgba(236,245,255,.55) → rgba(226,238,250,.18) → rgba(236,245,255,.45)` 的极淡蓝白光，保证文字可读。

字体：`HarmonyOS Sans SC / PingFang SC / Microsoft YaHei / system-ui`。当前图2总览的 KPI 主值为 29px/560、单位 17px、说明 14px；其他页面沿用玻璃主题层级。

主按钮：绿色渐变 `linear-gradient(180deg,#3aa06a,#2B8A57)`，白字；次按钮为白色半透明玻璃 + 8px 模糊。品牌标识保留琥珀色，仅作品牌识别，不参与按钮与状态强调。

## 3. 结构

- 顶栏：图2连续玻璃顶栏，自足能源AI 3.0 品牌、站点选择、页面目录、显示设置、报警、用户与时间。
- 页头：32px“站点总览”，同行健康摘要、查看健康和站点序号；总览不再显示副标题。
- KPI：总收益、储能收益、转换效率、今日电费、储能吞吐、光伏发电量、今日用电、最大需量；8 列、120px 高、6px 间距。
- 能流：默认 3D 能流，使用原始等距场站素材；能流图 / 2D能流 / 3D能流、趋势入口；第二工具栏提供等距/俯视、夜间显示、标签、全屏。
- 今日事件与调度状态位于能流面板底部；说明条与底部五项导航沿用图2结构。
- AI 管家默认收起为右下角圆形入口；面板只读本机点位、规则与报警，不联网、不调用云端模型、不下发控制。
- 桌面使用 1632×1000 设计坐标等比适配；长列表只在面板内部滚动。

## 4. 验收清单对照

| # | 检查项 | 实现 |
| --- | --- | --- |
| 1 | 背景不被整体模糊 | 背景照片无 blur，只按亮度设置调节 |
| 2 | 卡片有透视与背景模糊 | 卡片 `backdrop-filter: blur(24px) saturate(140%)`；背景可透出 |
| 3 | 双层渐变 | 125°，上缘 .86、下缘 .62 |
| 4 | 内高光 | `inset 0 1px 0 rgba(255,255,255,.32)`，重点卡片更强 |
| 5 | 半透白描边 | `1px solid rgba(255,255,255,.34)` |
| 6 | 主色只用语义色 | 主按钮绿色、链接/焦点蓝色、告警红色；品牌标识保留琥珀 |
| 7 | 圆角与间距 | 图2总览 KPI 9px/6px；能流及业务卡片 10px，卡片间距按各页布局 |
| 8 | 数字层级 | 图2总览主值 29px/560、单位 17px、说明 14px |

说明：Vite 的 CSS 目标会把 `backdrop-filter` 降级为 `-webkit-` 前缀，`frontend/index.html` 额外声明了标准属性，保证现代浏览器计算值仍是 `backdrop-filter`。

## 5. 显示设置

- 顶栏太阳图标打开；背景明暗 50–110%（默认 78%），玻璃透明度 30–90%（默认 62%）。
- 透明度映射到卡片渐变下缘；上缘固定为下缘 +0.24，默认即 .62 / .86。
- 设置写入本机 `localStorage`，刷新保持，可一键恢复默认。
- 管理员在同一面板可设置站点电价（元/kWh），保存到根节点 `easyemsTariff`；仅用于“今日用电 × 电价”的电费估算，不是分时电价或结算口径。

## 6. 10.1 寸单屏

- 高度 ≤820px 且宽度 ≥1000px 启用紧凑布局：顶栏、页头、底部导航固定，内容在舞台内排布。
- 总览：8 列 KPI、能流画布压缩、隐藏设备列表/最近变化与页脚。
- 通道、画面、报警、历史、规则、部署、分配器、账号、交付均在舞台内；长列表在面板内部滚动。
- 交付检查在桌面/10.1 寸使用双列列表，页头与摘要在固定区域，列表为唯一可滚动区。
- 决策表在 10.1 寸固定模拟与发布栏，仅规则行区域内部滚动；新增规则先显示加载态，等新规则加载后再允许编辑。
- 1280×800、1366×768、1024×768、1600×1000、1920×1080 逐页实测页面级、舞台级和页面根节点滚动差值均为 0；1024 决策表仅规则行区域 1px 取整差。

## 6.1 本地能源管家

- 入口：默认收起为右下角圆形 AI 入口；Esc 或关闭按钮收起。
- 数据：只读取当前站点快照中的点位、规则与报警；不访问网络，不调用云端模型，不执行控制。
- 回答边界：功率与能流、活动报警与错误、点位无值/超时、规则启用数量；无法回答时明确说明范围，不推测设备行为。
- 排版：372px 宽玻璃面板，标题、消息、建议问题、输入框与免责声明；1024×768 实测不超出视口，消息区内部滚动。

## 7. 决策表编辑器

- 数值输入允许清空、负数和小数，失焦后规整。
- 模拟提供“用当前值”、命中行高亮和“定位该行”；发布栏“最近命中”可点击定位。
- 支持复制行；默认行不在末尾时提示会拦截后续规则。
- 10.1 寸发布栏常驻，模拟面板保持在视口内；规则行很多时仅规则行区域内部滚动。
- 每行可编辑持续确认/冷却秒数；新增决策表先进入加载态，避免点击落到上一张规则；删除后回到默认规则。
- “最近一次求值”折叠面板展示输入/动作与拦截原因，数据来自 `lastCheck`；桌面端解释、模拟与发布固定，仅规则行滚动。
- 策略支持表格/详细双视图；表格内联持续、冷却、排序、复制、删除，整行点击进入详细编辑。10.1 下表格字号与控件单独放大。

## 8. 数据与诚实边界

- 能流节点只绑定已配置点位；没有数据时显示“—”，不填演示值。
- 背景照片只表达场景，不是数据源；场景中不出现未经配置的设备。
- KPI 与能流节点可点击下钻；没有匹配点位时进入通道页。
