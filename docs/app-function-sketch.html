交付人员的真实操作顺序
建站 → 接通道 → 套 Profile → 绑点位 → 建 EnergyUnit/PCC/组 → 配策略 → 试算 → 联调解锁 → 预检 → 发布 → 交接。当前每一段都能做，但"从已验收项目创建"和"包级发布"这两步要手动拼。
客户的真实操作顺序
登录 → 看总览 → 处理报警 → 需要时人工接管 → 查追溯 → 做备份/升级。除"升级"外全部可用；页面由开发预置，换站需要发版（A18）。
最快见效的三个补齐项
A08 15 分钟需量窗口、A09 96 点计划、A06 功率跟踪偏差——它们直接改变客户看到的"调度是否可信"，且不依赖项目包重构。
