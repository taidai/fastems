交付人员：重复交付

复用已验收资产，只处理变化与例外
从已验收项目创建填柜数、型号、地址和并网关系；系统列出复用项、变化项与待确认项。
批量换厂商Profile 一次应用整批柜体，逻辑点自动关联；缺回读等例外单列。
模板配策略填计划、需量限值和 PCC；特殊要求才开决策表，用同一输入试算。
按清单现场联调阻塞项直接显示原始读数、映射和验证步骤，处理后就地复验。
复用工程资产，不复制旧站地址、凭据和控制授权。
新设备默认待机，全部阻塞项解除后才能投运。

3

发布与交接

项目包上的一个动作
自动校验发布预检、仿真、打包、迁移、部署一次完成，失败即阻止投运。
验收交接自动汇总版本、输入、下发、回读、实测和遗留项，区分仿真与真机。
售后升级与回退共享那次操作的追溯，只确认新版与现场定制的冲突；历史保留，不回放旧命令。
不再单设交付中心。发布自动化；同事从上次位置接手，售后从真实追溯开始。

操作与版本
资源与逐 PCC 仲裁每个 PCC 明确反馈表与受影响资源；ResourceGroup 跨 Plant 不跨 Site，单元仅属一个有功组，逐 PCC 判定，不能用全站净额掩盖局部反送。
数据主权与版本回退JetStream 管配置与热状态，审计与命令日志为追加式 JSONL；关系库与 Outbox 未实现。回退只回退工程配置，升级后新增的报警、操作与审计继续保留。
命令与故障语义设定回读按编码/分辨率及提交后样本确认；实测另按容差与持续时间判断。故障动作按场景验证，不一律置零；失联显示结果未知，恢复前重读状态。
调度与交付硬优先级：安全 › 防逆流 › 逐 PCC 限值 › 组上限 › 需量 › 计划 › 电价。96 点计划与 15 分钟滑动需量已实现；缺 bin 时不做预测性削峰。升级按基线/定制/新版对照，回退保留运行历史且不回放旧命令。
协议与扩展Modbus 闭环 + OPC-UA 声明式接入已交付；MQTT 仅上行遥测，下行与设备凭据未实现。CAN、HTTP-REST、OCPP、外部 Broker 标扩展。
验收边界模拟器与真机证据分开，M5、多厂商互操作、ARM64 性能与独立用户试用单独签收；目标图不代表已完成。
