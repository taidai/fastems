# FastIOT 功能点汇报清单

日期：2026-11-07
用途：团队进度同步。软件功能已全部收口；真机验证（M5）尚未开始，是当前唯一关键路径。

## 一、项目定位

光储充 EMS：以 Simple IoT v0.31.0 为底座，Encore 单进程运行时（Linux 容器交付），
业务树 + 有序首条命中决策表 + Modbus TCP/RTU。离线、无代码、无云，每个动作可解释可审计。

## 二、功能清单（按模块，均已完成）

### 设备对象
- 设备台账：一台设备一行，业务节点/通道站号/Profile/健康/验证状态。
- 设备详情六页签工作区：概览、点位、命令、历史、报警、验证。
- 物模型：点位角色（遥测/遥信/电度/定值/压板）由 Profile 声明；`data/profiles/*.json` 自定义设备档案，同 ID 覆盖内置，无需改代码。

### 总览与画面
- 可配置 KPI（选择/排序/阈值）、健康摘要下钻、班次交接、常用命令入口。
- 运行画面模板/版本回滚/内嵌趋势与报警角标。

### 点位与通道
- 点位角色分类、质量原因、行内趋势、保存筛选视图、批量命令。
- 通道线路测试（只读不发配置）、扫描内联、端口配置 diff/模板、单通道重启。

### 调度（决策表 + 分配器）
- 决策表：多输入 AND、多输出顺序执行、首条命中、草稿/发布/启用/模拟独立。
- 规则增强：时间窗口（跨午夜/星期）、场景测试集、策略模板、版本 diff、历史回放、依赖图。
- 分配器：SOC/温度/电网约束、优先级/权重、分配历史、死区、成员接管、模拟分配。

### 虚拟聚合
- 时间窗口（瞬时/5m/15m/1h）、质量策略（忽略/计数/降级）、虚拟告警、报表绑定。

### 报警与历史
- 报警分组/根因、60s 洪泛抑制、确认备注、点位趋势下钻、CSV 导出。
- 历史报表模板、保存查询、多设备对比、报警叠加、数据质量摘要。

### 部署、账号与审计
- 接入向导五步（扫描→绑 Profile→映射→只读核对→记录验证人）、点表 diff、通信测试报告、交付证据包（zip）。
- 动作级权限（角色 + 动作白名单，默认拒绝）、会话超时/并发/密码重置。
- 审计业务化（登录/点表配置/命令执行/报警处理等 11 类动作 + 业务对象）。

### 命令与持久化
- 命令带 request_id、回读确认、影响预览、参数预设；命令历史持久化（重启后可见、幂等）。
