## 验收结果

- 完整 `go test ./...`、Modbus TCP/RTU 协议测试和真实浏览器清单通过。
- 资源重命名、编辑、停用、合法/非法移动、依赖删除保护均实测。
- 规则复制默认未发布且停用；发布历史可恢复。
- 命令已接受、已回读、结果未知和重复请求均验证。
- CSV 预检不创建点位，确认后导入；导出文件可再次导入。
- 型号模板可保存、应用，且不包含源节点 ID、业务 ID 或凭据。
- 交付检查能发现未轮询连接；心跳完成后恢复通过。备份与现场验收保留明确警告。
- 完整数据目录离线恢复通过。
