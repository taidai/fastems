—建站向导 / 项目包 / 升级回退 / 交接清单 / 配置生成页面交付 › 项目、交付交付新增；对应 A01、A17、A13、A14、A18，均未实现
一个入口对应一个角色任务客户不需要在"配置"和"运行"之间做选择；交付也不需要去运行页里找配置入口。跨角色的页面只在联调时由交付临时进入。
权限靠判定，不靠隐藏菜单里看不到不等于访问不了；跨站请求一律 403，隐藏只是减少误操作。交付与客户的边界必须由后端范围校验兜底。
缺口页用空位表达建站向导、项目包、包级发布、配置生成页面现在都不存在；导航总览把它们画成虚线空位，而不是先挂一个假入口。
导航总览只回答"东西放在哪、谁能看见"；每个页面内部长什么样，见交付工作台与客户工作台两张线框。
