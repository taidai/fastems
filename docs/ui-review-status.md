# 界面评审待办收口状态

日期：2026-11-07
范围：`docs/ui-review-final.md` 与 `docs/full-module-roadmap.md` 中已经明确的待办；不含 M5 真实设备签收。

## 已完成

### 设备对象
- 设备详情改为完整工作区：概览、点位、命令、历史、报警、验证六个页签。
- 台账主名称优先业务节点/通道，未绑定 Profile 提供“去绑定”入口。
- 点位页显示角色、映射、当前值、质量原因；支持最近一小时行内趋势。
- 命令页显示可用性、原因、参数、影响预览、执行记录；支持参数预设（本机保存）。
- 历史页支持 1 小时/24 小时/7 天和原始/5 分钟/1 小时聚合。
- 报警页支持确认备注、关闭和点位趋势下钻。
- 验证页提供 Profile/映射/命令/在线/验证五项清单，保存验证人、日期、序列号和说明，并可导出验证记录。

### P0 可信与可用
- 部署页不再显示“501 尚未接线”；运行状态接口已接通，失败时显示真实错误。
- 审计动作与对象业务化：登录、端口配置、点表配置、设备模型、命令执行、控制写入、决策表、报警处理、账号管理、站点设置、验收。
- 写值、命令、规则发布、规则删除统一使用确认对话框。
- 10.1 布局：KPI 在 1024 宽度改为 4×2；台账汇总卡片提高最小高度；点位表在 1024 隐藏格式/缩放/更新时间并提高行高；设备工作区为独立全屏、不参与页面缩放。
- 设备数据查询从导航移除，由设备台账/历史承担；交付检查从导航移除，从“部署与验收”进入。
- Profile/CSV 在部署页和通道工具仍有两个入口，属于施工期与运维期的不同场景；尚未彻底合并。
- 历史默认选择最近有数据的点位，不再默认无数据点位。
