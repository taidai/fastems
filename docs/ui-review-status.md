## 已完成

### 设备对象
- 设备详情改为完整工作区：概览、点位、命令、历史、报警、验证六个页签。
- 台账主名称优先业务节点/通道，未绑定 Profile 提供“去绑定”入口。
- 点位页显示角色、映射、当前值、质量原因；支持最近一小时行内趋势。
- 命令页显示可用性、原因、参数、影响预览、执行记录；支持参数预设（本机保存）。
- 历史页支持 1 小时/24 小时/7 天和原始/5 分钟/1 小时聚合。
- 报警页支持确认备注、关闭和点位趋势下钻。
- 验证页提供 Profile/映射/命令/在线/验证五项清单，保存验证人、日期、序列号和说明，并可导出验证记录。

- 设备数据查询从导航移除，由设备台账/历史承担；交付检查从导航移除，从“部署与验收”进入。

### 第二轮新增完成（2026-11-07）
- **物模型升级**：点位角色由 Profile 声明（`point_specs[].role`），不再只靠前端按名称猜；设备详情点位页与绑定映射表按声明显示角色徽标。全局点位表对未绑定 Profile 的原始点位仍按名称/类型推断。
- **自定义 Profile**：`data/profiles/*.json` 加载用户自定义设备档案，ID 相同覆盖内置条目；无效文件启动日志与绑定页面都会说明原因，见 [`custom-profiles.md`](custom-profiles.md)。
- **命令历史持久化**：命令结果写入 `data/commands.jsonl`（保留最近 500 条请求的最终状态）；重启后历史可见，进行中的命令恢复为"结果未知（进程重启）"，恢复的记录不会重新触发报警；request_id 幂等跨重启有效。
- **通信测试报告**：通道页"通信报告"导出 CSV——通道/设备轮询统计、成功率、延迟、最近错误与各设备点位质量汇总，交付时附在验证记录后。
- **点位保存筛选视图**：筛选组合可保存为命名视图（本机保存），一键套用/删除。
- 仓库建立 git 基线（分模块提交），删除设备数据查询死代码与重复样式。

### 第三轮新增完成（2026-11-07，规则引擎增强）
- **规则时间条件**：行条件新增"时间"类型——时间窗口（HH:MM–HH:MM，支持跨午夜，站点本地时间）加星期勾选（跨午夜窗口的星期按窗口开始日计算）；引擎在 `internal/decision` 判定，命中解释（最近一次求值）与模拟结果都写明时间条件满足与否；单测覆盖跨午夜与星期边界。
- **模拟时刻**：模拟面板可指定模拟时刻（留空=现在），只影响模拟，绝不写设备。
- **场景测试集**：一张决策表可保存多组"输入组合（含模拟时刻）→期望命中行/期望输出"，一键全部运行并逐条显示通过/失败（行不符/输出不符/无法模拟）；场景存在草稿文档里，运行引擎忽略，不影响发布版本行为与版本差异比较。

### 第三轮新增完成（2026-11-07 交付类 P2）
- **接入向导**：部署页"接入向导"五步引导——选择通道/站号（支持只读扫描或直接从设备列表选择）→ 绑定 Profile（按名称自动匹配点位）→ 映射点位（命令引用的变量标记必填）→ 只读核对（当前值/质量每 2 秒刷新，不写设备）→ 记录验证人。每步复用既有接口（`/ems/scan`、`/modbus/{ch}/units/{n}/model`、`/ems/state`），不新增后端状态。
- **点表 diff**：部署页导入 CSV 先"查看差异"——按名称对比当前点表，列出新增/修改（字段级 前值→新值）/CSV 中缺失/不变；"确认应用"才写入（`io/import?apply=diff`）。缺失点位默认保留，勾选后才随应用删除；通道工具页的原预检/导入流程不变。
- **交付证据包**：部署页一键导出 zip（`/api/delivery/evidence`）——设备台账、验证记录、通信测试报告（复用 `/api/ems/quality` 数据源与点位质量汇总）、最近 30 天报警统计，附边界说明；导出内容不含密码/令牌（集成测试断言 zip 字节不含管理员口令）。

### 第三轮新增完成（2026-11-07 报警增强）
- **报警分组/根因**：报警记录携带 `root_cause`（触发它的点位/规则/设备 ID，由 point_id 优先、否则 device_id 派生）；同根因的多条报警聚合为一条主报警 + 子项列表（子项带 `group_id` 指向主报警），前端按根因展开/收起并可下钻到根因点位趋势，CSV 导出补根因与次数列。
- **洪泛抑制**：同 key 在 60 秒内状态重复翻转不重复新增记录，只累加出现次数（`count`）与最后触发时间（`last_raised_at`），不重发 `raised` 事件、不重置发生时间；超过窗口的复归才作为新记录。
- `internal/ems/alarm` 新增单测覆盖分组与洪泛抑制（含窗口边界与重复翻转累加）。

### 第四轮新增完成（2026-11-07，虚拟聚合增强）
- **聚合时间窗口**：聚合支持滚动窗口（瞬时/最近 5 分钟/15 分钟/1 小时），窗口内每个成员取其样本均值参与聚合；结果解释写明窗口起止与参与成员数。
- **聚合质量策略**：坏成员（过期/无值）如何影响聚合可配置——忽略 / 按坏值计（默认，部分有效）/ 整体降级；纯函数单测覆盖三种策略的质量传播。
- **虚拟聚合告警**：聚合值可配上限/下限与级别，超限通过现有告警引擎产生告警（只读调用 `Raise`/`Clear`，未改告警实现），回到区间自动清除。
- **聚合报表绑定**：聚合值落为业务节点上的 `easyemsAggregateValue` 点，可被历史/报表按 node_id 引用。

### 第五轮新增完成（2026-11-07，报表与历史）
- **报表模板 / 保存查询**：历史查询组合（对比点位、时间范围、聚合间隔）可保存为命名模板，一键套用、覆盖或删除（本机 localStorage，`easyems-history-queries`）。
- **多设备对比**：历史趋势改为按时间轴叠加多条点位曲线（多序列 + 图例，图例按序列颜色区分并显示各自最近值）。
- **报警叠加**：趋势图叠加所选时间范围内与所选点位相关的报警事件标记（只读 `/ems/alarms`，悬停看标题与时间，可开关）。
- **数据质量摘要**：趋势图旁汇总所选时间段的质量占比（正常/过期/无效/无值），数据来自运行时 `/ems/state`（点位→设备映射）与 `/ems/history`（带质量的样本）；仅统计已接入运行时的 Modbus 点位。

### 第六轮新增完成（2026-11-07，点位与通道工具）
- **批量命令**：点位表多选可写点位后，一次下发同一目标值到多个点位——复用单点写值链路（`/nodes/{id}/value`），带确认对话框列出目标列表（当前值 → 目标值），逐点下发并等待回读；选中含线圈时限制目标值 0/1。
- **通道线路测试**：通道页新增只读"线路测试"——按通道自身持久化参数打开传输，逐站号读保持寄存器/输入寄存器探测连通性与站号可读性，不动配置、不下发写（`/modbus/{id}/line-test`，单测覆盖 TCP 在线/离线与节点参数还原）。
- **扫描内联**：通道页直接扫描站号并把结果内联展示（复用 `/ems/scan`），不必跳到部署页；运行中的通道返回"通道占用"并提示改看单元列表。
- **端口配置 diff/模板**：编辑端口时保存前展示"前值 → 新值"逐字段 diff；端口参数可保存/套用为本机模板（localStorage `easyems-port-templates`）。

### 第七轮新增完成（2026-11-07，调度增强）
- **分配器成员约束**：成员可加 SOC/温度/电网等越限约束（输入点位 + 比较 + 限值 + 作用方向），越限时自动降载（限充电/限放电）或剔除并给出原因；优先级（越大越先分配）与权重（比例偏好）参与分配；死区（小幅波动不重分配）；成员级人工接管；分配历史记录每次分配快照（成员份额、原因、回读状态）；模拟分配只计算不下发。`internal/decision` 新增约束/死区/模拟单测。
- **规则策略模板**：预置"峰谷套利、SOC 保护、需量削峰"三个策略模板，一键套用后按本机点位重新绑定输入与输出。
- **版本 diff / 历史回放 / 依赖图**：两个发布版本逐行对比（新增/删除/修改，字段级变化）；对某版本在某时刻重放已发布规则（纯模拟不下发）；生成"输入点位—规则行—输出点位"的引用关系依赖图。`internal/decision` 新增版本 diff/回放单测。

### 第八轮新增完成（2026-11-07，总览与画面）
- **可配置 KPI**：总览 KPI 卡可选择、排序、设置阈值（本机 localStorage `easyems-kpi-config`），按配置渲染，超阈值变色并加角标；未配置时保持默认八项指标。
- **健康摘要下钻**：页头告警 / 核心设备离线 / 核心测点陈旧改为可点击胶囊，点击展开对应通信详情（离线通道的协议、地址、最近轮询与错误数，或陈旧点位的当前值与未更新时长）。
- **班次交接**：记录交接班次、值班人、备注（本机 localStorage `easyems-shift-handovers`），可导出 CSV（不含任何密码）。
- **常用命令入口**：总览"常用命令"列出各设备 Profile 可用命令（复用 `/device-ledger` 与 `/modbus/{ch}/units/{n}/model`），执行走确认对话框并等待回读（复用命令下发链路）。
- **画面模板与版本回滚**：运行画面可保存当前布局为模板、套用/删除模板（本机 localStorage `easyems-screen-templates`）；每次保存画面自动记录版本快照（`easyems-screen-versions:{nodeId}`），可回滚到历史版本。
- **画布内嵌趋势/报警**：画面卡片内嵌迷你趋势（复用点位历史接口）与报警状态角标（只读 `/ems/alarms`，按点位/设备计数）。

### 第九轮新增完成（2026-11-07，动作级权限与会话策略）
- **动作级权限**：`AccessPolicy` 新增 `actions` 白名单；集中式 `canAction(identity, action)` 与 11 个动作常量（配置/写值/命令执行/规则发布/报警确认/报警维护/删除/导出/账号管理/审计查看/站点设置）；角色保留为默认动作集快捷方式，白名单覆盖角色默认，未知动作默认拒绝。`canConfigure`/`canOperateIdentity` 保留为角色默认谓词。
- **路由细化**：`internal/appapi/*.go` 与 `internal/emsapi` 的 `access.Admin/Configure/Operate` 判断细化为具体动作；报警确认/关闭新增动作校验（此前任何登录者可确认报警）。
- **账号管理**：`GET /users` 列出账号与动作、`PUT /users/{id}` 编辑角色与白名单、`POST /users/{id}/password` 管理员重置他人密码（口令仅写入本机账号节点，不记审计/导出）；前端账号页支持逐账号勾选动作白名单与重置密码。
- **会话策略**：登录签发 easyems 会话令牌（不再直发上游 token）；会话空闲超时（默认 30 分钟，`EASYEMS_SESSION_TIMEOUT_MINUTES` 可配）+ 同账号并发会话上限（默认 5，`EASYEMS_MAX_SESSIONS` 可配）；前端按快照返回的超时主动退出。审计记录不含密码/令牌。
- **单测**：`internal/appapi/permission_test.go` 表驱动覆盖 admin/implementer/operator/viewer × 全部动作，及白名单覆盖、默认拒绝、管理员豁免。
