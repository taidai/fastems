# easyems 验收记录

日期：2026-11-03。测试使用固定 Simple IoT v0.31.0、Go 1.27.3、Node 24.12.0。

## 已实际通过

- `go test ./...` 与 `go test -race ./...`：全部通过。
- 决策表：多条件 AND、多输出顺序、首条命中、排序、默认不动作、草稿/发布/启用/模拟分离。
- 重启恢复：策略和值恢复，启动时不重复执行当前命中行。
- 人工接管：自动规则不覆盖人工目标；恢复自动后立即重新评估。
- 换来源：业务 ID 和规则不变，只有绑定目标改变；旧来源不再收到该规则输出。
- 权限：本人登录、默认无策略拒绝、查看者不能写设备或发布规则；通用 `/v1` 与 `/old` 在产品模式返回 404。
- Modbus TCP：真实只读请求返回寄存器 253，缩放显示 25.3；人工写入与回读成功；35.1 触发决策表改变真实服务端线圈。
- Modbus RTU：通过 Linux PTY 虚拟串口跑真实 RTU 帧，完成读取、规则控制和断线过期输入阻断。
- CSV：有效中文点表导入成功；含无效行的批次不留下部分点位。
- 浏览器：使用本机 Edge Chromium 实际完成登录、建组、4 个测试点位、两输入/两输出、模拟零写入、发布、启用、人工接管/恢复、桌面和移动布局；控制台无错误。
- 离线恢复：停止后复制完整数据目录，在独立目录和端口启动；管理员登录、设备树、规则及输出值均通过检查。
- 产物：`easyems.exe` 是单文件 Windows 应用，约 34.2 MiB；运行时不需要 Node、HA、外部 NATS 或第二 HTTP 服务。
- 交付构建：最新源码已通过 Docker 多阶段干净构建，镜像为 `easyems:local`。
