# 设备与点位工作台 — 批量操作实测

日期：2026-11-05
环境：本地 Modbus TCP 模拟器（两个通道、7 个常驻点位）

## 步骤与结果

1. 在“设备”页打开点位表：7 行；统计为全部 7 / 正常 7 / 过期 0 / 离线 0 / 可写 2。
2. 搜索“Modbus”将结果缩到 5 行；清空搜索恢复 7 行。
3. 创建临时点位“批量测试点”（保持寄存器，站号 1，地址 999，只读），页面出现第 8 行。
4. 勾选临时点位：批量栏显示“已选 1 / 筛选 8 / 全部 8”；导出 CSV 下载 `easyems-points.csv`。
5. 批量停用：行显示“已停用”，质量列显示“已停用”。
6. 批量启用：行恢复；因 999 地址无模拟数据，质量显示“离线”，符合预期。
7. 批量删除：确认后临时点位从表中移除，剩余 0 行匹配；常驻 7 个点位不变。
8. 详情抽屉：显示实时值、质量、通道、站号/地址、类型/格式、缩放/单位、读写状态；可打开编辑表单。
9. 写值回读：对可写的“Modbus 线圈”下发 1（与当前值相同），最近命令变为“已回读”，实时值仍为 1 °C。
10. 行内编辑：创建临时点位“编辑测试点”，把缩放改为 2、单位改为 kWh，保存后表格显示“2 / kWh”；通过 API 删除临时点，返回 200。
11. 批量改缩放/偏移：创建两个临时点位，批量缩放先填 0 被拒绝（“缩放必须是非 0 数字”）；改为缩放 2、偏移 10 后应用，两行显示“2 / x”，API 读取 scale=2、offset=10；提示“已更新 2 个点位的缩放 / 偏移”。临时点已删除。
12. 按通道批量新增：前缀“批量新增测试-”、起始地址 900、数量 3、步长 2，预览为 900/902/904；创建后 3 个点位出现且选中，提示“已新增 3 个点位”。再次用同名创建被拒绝“名称与现有点位冲突：批量新增测试-1”；3 个临时点已清理。
13. 布局：1280×800、1024×768、1366×768 下页面级、舞台级、表格内部和横向滚动差值均为 0。

无控制台错误；临时点位已删除，预览数据恢复。
